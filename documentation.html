CharityPress — Installation v1.0.0

Installation Guide

Follow these steps carefully to get CharityPress running on your server.

✅ Before You Start
Make sure you have created a MySQL database and have the database credentials ready before starting the installation.

Step-by-Step Installation

1

Upload Files to Server

Extract the ZIP file and upload all files to your server's web root (e.g. public_html/ or /var/www/html/).

2

Configure the .env File

Copy .env.example to .env and fill in your database and app details. 

cp .env.example .env
3

Install PHP Dependencies

composer install --optimize-autoloader --no-dev
4

Generate Application Key

php artisan key:generate
5

Run Database Migrations

php artisan migrate --seed

This creates all tables and seeds the database with default admin account and demo data.

6

Install Frontend Assets

npm install
npm run build
7

Set Storage Permissions

chmod -R 775 storage bootstrap/cache
php artisan storage:link
8

Configure Web Server Document Root

Set your web server document root to the public/ folder, not the root of the project.

# Nginx example
root /var/www/charitypress/public;
🎉 Done!
Navigate to yourdomain.com/admin/login to access the admin panel. See the Demo Login section for default credentials.

.env Configuration

The .env file is the heart of your application configuration. Here is a full reference.

📄 Full .env Reference

APP_ENV=production

DB_USERNAME=your_db_user

# ─── Mail ───────────────────────────────────────────────
MAIL_MAILER=smtp
MAIL_HOST=smtp.yourprovider.com
MAIL_PORT=587
MAIL_USERNAME=your@email.com
MAIL_PASSWORD=your_email_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@yourdomain.com
MAIL_FROM_NAME="${APP_NAME}"

# ─── Stripe ─────────────────────────────────────────────
STRIPE_KEY=pk_live_xxxxxxxxxxxx
STRIPE_SECRET=sk_live_xxxxxxxxxxxx
STRIPE_WEBHOOK_SECRET=whsec_xxxxxxxxxxxx

# ─── Social Login ───────────────────────────────────────
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

FACEBOOK_CLIENT_ID=
FACEBOOK_CLIENT_SECRET=

Mail / SMTP Setup

CharityPress uses email for password resets, donation receipts, and newsletter campaigns. Configure SMTP in your .env file.

Gmail SMTP Example

MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=yourname@gmail.com
MAIL_PASSWORD=your_app_password    # Use App Password, not your main password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=yourname@gmail.com
ℹ️ Gmail App Password
For Gmail, you must use an App Password, not your regular password. Go to Google Account → Security → 2-Step Verification → App Passwords to generate one.

CharityPress — Stripe Setup v1.0.0

Stripe Payment Setup

CharityPress uses Stripe for processing one-time and recurring donations.

💳 Getting Your Stripe Keys

1

Create Stripe Account

Go to stripe.com and create a free account.

2

Get API Keys

Go to Developers → API Keys. Copy your Publishable key and Secret key.

3

Set Webhook

Go to Developers → Webhooks → Add endpoint. Set URL to yourdomain.com/stripe/webhook and select events: checkout.session.completed, invoice.payment_succeeded.

4

Add to .env

STRIPE_KEY=pk_live_xxxxxxxxxxxx
STRIPE_SECRET=sk_live_xxxxxxxxxxxx
STRIPE_WEBHOOK_SECRET=whsec_xxxxxxxxxxxx
🧪 Testing Stripe
Use test keys (pk_test_... and sk_test_...) during development. Test card number: 4242 4242 4242 4242, any future expiry, any CVC.
CharityPress — Social Login v1.0.0

Social Login Setup

CharityPress supports login via Google and Facebook using Laravel Socialite.

🔵 Google Login Setup

1

Create Google OAuth App

Go to console.cloud.google.com → Create Project → APIs & Services → Credentials → Create OAuth Client ID.

2

Set Authorized Redirect URI

Add: https://yourdomain.com/auth/google/callback

3

Copy Credentials to .env

GOOGLE_CLIENT_ID=your_client_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_client_secret
GOOGLE_REDIRECT_URI=https://yourdomain.com/auth/google/callback

🔷 Facebook Login Setup

1

Create Facebook App

Go to developers.facebook.com → My Apps → Create App → Consumer.

2

Add Facebook Login Product

In your app dashboard, add the Facebook Login product and set the redirect URI.

3

Copy Credentials to .env

FACEBOOK_CLIENT_ID=your_app_id
FACEBOOK_CLIENT_SECRET=your_app_secret
FACEBOOK_REDIRECT_URI=https://yourdomain.com/auth/facebook/callback

CharityPress — Programs v1.0.0

Programs Management

Programs are the core content of your charity. Each program represents a cause or campaign your organization is running.

🎯 Managing Programs

  • Go to Admin → Programs
  • Click Create Program to add a new one
  • Fill in: Title, Description, Image, Category, Goal Amount, Permalink
  • Programs are displayed on the public /programs page

📂 Program Categories

Organize programs by category. Go to Admin → Programs → Categories to manage them.

🏷️ Program Attributes

Add custom attributes (e.g. "Location", "Duration") to programs via Admin → Programs → Attributes.

CharityPress — Updating v1.0.0

Updating CharityPress

When a new version is released, follow these steps to update safely.

⚠️ Always Backup First!
Before updating, always backup your database and all files. You can use mysqldump or your hosting control panel backup tool.
1

Backup your site

Backup database and storage/ folder.

2

Download new version

Download the latest version from CodeCanyon → Downloads.

3

Replace files

Upload and overwrite all files except your .env file and storage/ folder.

4

Run update commands

composer install --optimize-autoloader --no-dev
php artisan migrate
npm install && npm run build
php artisan config:cache
php artisan route:cache
CharityPress — Support v1.0.0

Support

💬 How to Get Support
Support is provided through the CodeCanyon comments section and our dedicated support email. Response time is within 24–48 hours on business days.

📋 Before Contacting Support

  • Read through this documentation carefully
  • Check that your server meets all requirements
  • Check your .env file is correctly configured
  • Check storage/logs/laravel.log for error messages
  • Try running php artisan config:clear && php artisan cache:clear

📝 When Contacting Support, Include

  • Your purchase code from CodeCanyon
  • PHP version and server type
  • A description of the issue
  • Any error messages from the browser console or Laravel log
  • Steps to reproduce the issue
ℹ️ Support Scope
Support covers bugs and issues with the product as delivered. It does not include custom feature development, general Laravel help, or third-party plugin issues.
